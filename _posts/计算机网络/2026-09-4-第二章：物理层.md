# 物理层的基本概念

**物理层负责在传输媒体上传输原始比特流 `0/1`**。它不关心这些比特具体表示什么，只负责解决“比特怎样真正从一台设备传到另一台设备”。

物理层的核心任务是规定设备与传输媒体之间如何连接和通信，包括接口形状、信号电平、各引脚作用以及通信过程等，通常概括为**机械特性、电气特性、功能特性和过程特性**。

例如发送一个 `1`，物理层需要规定这个 `1` 到底用什么物理信号表示，可能是某个电压、电流、光脉冲或无线电波。

需要注意：

**传输媒体本身不属于物理层，而位于物理层之下。**
物理层规定如何利用传输媒体传输比特，传输媒体则真正承载电磁信号。

可以简单理解为：

```text
数据链路层
   ↓
物理层：规定怎么发送 0 和 1
   ↓
传输媒体：真正承载信号
```

# 传输媒体

传输媒体**是发送设备和接收设备之间传输电磁信号的物理通道，主要分为**导引型传输媒体**和**非导引型传输媒体。

## 导引型传输媒体

导引型传输媒体中，信号沿着实体线路传播，常见的有双绞线、同轴电缆和光纤。

| 传输媒体 | 特点            | 常见场景       |
| ---- | ------------- | ---------- |
| 双绞线  | 便宜、布线方便、距离较短  | 以太网、电话线    |
| 同轴电缆 | 抗干扰能力较强       | 有线电视、早期以太网 |
| 光纤   | 带宽大、距离远、抗电磁干扰 | 骨干网、宽带接入   |

**双绞线**由两根绝缘铜线相互缠绕，通过绞合减少外界电磁干扰和线间串扰。常见网线如 Cat5e、Cat6 都属于双绞线。

**同轴电缆**由中心导体、绝缘层、屏蔽层等组成，屏蔽性能比普通双绞线更好，但在现代局域网中已经较少使用。

**光纤**利用光信号传输数据，主要由纤芯和包层组成。光在纤芯内部利用全反射向前传播，因此损耗低、传输距离远，同时不会受到电磁干扰。



## 非导引型传输媒体

非导引型传输媒体没有实体导线，信号通过空间中的**电磁波**传播，例如无线电波、微波、红外线等。

```text
注意电磁波传播理论速度上是比光纤快，
但由于无线电这种方式携带数据的频率和带宽有限，实际传输速率通常比光纤慢很多。
```

无线通信本质上都是利用不同频率的电磁波，例如 Wi-Fi、蓝牙、4G/5G、卫星通信等。

无线传输的优点是移动方便、部署灵活，但更容易受到干扰、衰减和窃听，因此可靠性和安全性通常比有线环境更复杂。


# 编码与调制

编码与调制的目的都是把数据转换成适合信道传输的物理信号。 一般来说，数字数据直接变成数字信号称为**编码**，数字数据加载到模拟载波上称为**调制**。

```text
数字数据 → 编码 → 数字信号
数字数据 → 调制 → 模拟信号
```

基带信号是数据直接形成、尚未调制到高频载波上的原始信号。数字信号中，每一种表示离散数值的基本波形称为**码元（Symbol）**。

如果一种编码或调制方案规定每个码元有 \(M\) 种可区分的信号状态，那么每个码元最多可携带 \(\log_2 M\) bit 信息。

```text
比如一个码元有 4 种电平，分别表示 +3V、+1V、-1V、-3V，则可以表示 2 bit：
+3V → 00
+1V → 01
-1V → 10
-3V → 11 
```

又例如模拟载波中的16-QAM 有 16 种码元，因此一个码元可以携带 \(4bit\)。

## 常见数字编码

### 不归零编码 NRZ

在一个比特周期内持续保持高电平或低电平表示 `0/1`。

优点是简单、所需带宽较小，但如果连续出现很多相同的比特，信号长时间不发生变化，接收端难以从信号中恢复时钟，因此存在**同步问题**。

### 归零编码 RZ

每个比特周期内信号都会回到零电平，因此能提供一定的时钟信息，但信号变化频繁，占用带宽较大，编码效率较低。

### 曼彻斯特编码

**每个比特中间必然发生一次电平跳变**，这个跳变既用于表示数据，也可以帮助接收端同步时钟，因此具有自同步能力。

```text
每个 bit 中间一定跳变 → 可以提取时钟
```

缺点是信号变化频率较高，同样的比特率下需要比 NRZ 更大的带宽。传统以太网曾采用曼彻斯特编码。

### 差分曼彻斯特编码

每个比特中间同样一定发生跳变，用于时钟同步；**数据由比特开始位置是否发生跳变来表示**。

它的优势是接收端主要判断“有没有变化”，而不是判断绝对高低电平，因此即使线路极性接反也不容易造成数据整体翻转。

> 差分曼彻斯特并不是比普通曼彻斯特更节省带宽，两者都需要频繁跳变；主要优势是抗极性反转能力更强。

| 编码     | 核心特点            | 主要问题       |
| ------ | --------------- | ---------- |
| NRZ    | 高低电平直接表示数据      | 连续相同比特时难同步 |
| RZ     | 每个比特内回到零电平      | 带宽利用率低     |
| 曼彻斯特   | bit 中间必跳变，自同步   | 占用带宽较大     |
| 差分曼彻斯特 | 中间跳变同步，起始跳变表示数据 | 同样需要较大带宽   |

## 基本调制方法

调制是在一个高频**载波**上改变某些参数来表示 `0/1`。载波可以写成：

$$
s(t)=A\cos(2\pi ft+\varphi)
$$

因此可以改变三个量：振幅 \(A\)、频率 \(f\)、相位 \(\varphi\)。

**调幅 AM**通过改变振幅表示数据，**调频 FM**通过改变频率表示数据，**调相 PM**通过改变相位表示数据。

```text
AM：振幅变
FM：频率变
PM：相位变
```

实际数字通信中通常称为 ASK、FSK、PSK，本质上分别对应对载波振幅、频率和相位进行数字调制。

```text
注意即使调整幅、频、相位，载波本身仍然是连续的模拟信号， 因为在调整之后他们会进行平滑处理。
```

### QAM 正交振幅调制

QAM（Quadrature Amplitude Modulation）同时改变载波的振幅和相位，因此一个码元可以表示多个 bit，比单纯只改变振幅或相位能携带更多数据。

例如 **16-QAM** 有 16 种不同码元：

$$
\log_2 16=4bit/码元
$$

所以一次发送一个码元，就相当于传输了 4 bit。

这些码元通常表示在**星座图**上，每个点对应一种振幅和相位组合。实际系统通常采用**格雷码**排列相邻码元，使相邻两个点只相差 1 bit，这样即使噪声导致码元误判到附近位置，产生的比特错误也更少。

QAM 阶数越高，一个码元携带的 bit 越多，例如：

$$
16QAM=4bit/码元,\quad 64QAM=6bit/码元,\quad 256QAM=8bit/码元
$$

但阶数越高，星座点越密集，对信噪比要求也越高，更容易受到噪声影响。

# 信道的极限容量

## 奈氏准则

**奈氏准则描述理想无噪声、带宽受限信道中，为避免码间串扰，码元传输速率存在上限。**

$$
R_s^{max}=2W\quad \text{Baud}
$$

其中 \(W\) 为信道带宽（Hz），\(R_s\) 为码元速率（Baud）。

如果一种传输方案有 \(M\) 种可区分的码元状态，则每个码元最多携带：

$$
\log_2 M\ bit
$$

因此理想信道的最高数据率为：

$$
R_b^{max}=2W\log_2M \quad bit/s
$$

例如带宽 \(W=3kHz\)，采用 4 种码元状态：

$$
R_b^{max}=2\times3000\times\log_2 4=12kb/s
$$

奈氏准则说明：**带宽一定时，不能无限提高码元速率；想继续提高比特率，可以让一个码元携带更多 bit，即采用多进制编码或调制。**

## 香农公式

真实信道存在噪声，即使不断增加码元状态数，也不可能无限提高速率，因为码元越密集，接收端越难区分。

香农公式给出了有噪声信道能够可靠传输信息的理论最大速率：

$$
C=W\log_2(1+\frac{S}{N})
$$

其中 \(C\) 为信道容量（bit/s），\(W\) 为带宽，\(S/N\) 为信噪比。

信噪比常用 dB 表示：

$$
SNR_{dB}=10\log_{10}\frac{S}{N}
$$

```text
注意一个奈氏准则是无噪下的理论极限，香农公式是有噪声下的理论极限。
```

因此提高信道容量主要有两个方向：增加带宽 \(W\) 或 提高信噪比 \(S/N\)。但信噪比提高带来的收益是对数增长，并不是成比例增长。

## 总结

|      | 奈氏准则         | 香农公式       |
| ---- | ------------ | ---------- |
| 考虑噪声 | 否            | 是          |
| 限制对象 | 码元速率 / 数据率   | 信息传输速率     |
| 核心限制 | 带宽导致的码间串扰    | 带宽 + 噪声    |
| 提高速率 | 增大带宽、增加码元状态数 | 增大带宽、提高信噪比 |

- 奈氏准则：码元不能发得无限快
- 香农公式：即使增加码元状态数，真实信道的数据率也不可能无限提高。
