# 因特网概述

因特网（Internet）是“网络的网络”，由大量计算机网络通过路由器互联形成。网络中的主机负责运行应用程序，交换机和路由器负责转发数据，通信链路负责传输数据，通信双方按照统一的**网络协议**进行通信。

**协议（Protocol）** 就是通信双方必须遵守的规则，主要规定数据的格式、发送顺序以及收到数据后如何处理。例如 TCP、IP、HTTP 都属于网络协议。

# 三种交换方式

**电路交换**：通信前先建立一条专用通信路径，通信过程中资源一直被占用，通信结束后释放。优点是速率和时延比较稳定，缺点是链路利用率低，传统电话网络主要采用这种方式。

**报文交换**：以完整报文为单位进行**存储转发**，中间节点收到完整报文后再向下一节点发送。不需要独占链路，但报文较大时需要较多缓存，并且等待时间较长。

**分组交换**：将报文拆成多个较小的**分组（Packet）**，每个分组都包含首部和数据，并逐个进行存储转发。多个用户可以共享链路，因此链路利用率高，但网络繁忙时会产生排队、时延甚至丢包。**现代因特网主要采用分组交换。**

| 交换方式 | 核心特点 | 主要缺点 |
|---|---|---|
| 电路交换 | 先建立连接，独占资源 | 利用率低 |
| 报文交换 | 整个报文存储转发 | 时延大、缓存需求大 |
| 分组交换 | 报文分组，共享链路 | 可能排队、丢包 |

# 计算机网络的定义和分类

**计算机网络**是将多个独立的计算机系统通过通信链路和网络设备连接起来，并按照网络协议实现数据通信和资源共享的系统。

按覆盖范围通常分为 **PAN（个人区域网）、LAN（局域网）、MAN（城域网）、WAN（广域网）**。LAN 常见于家庭、公司和校园；WAN 通常跨城市、跨国家。

需要注意：**LAN、WAN 描述的是网络覆盖范围，而 AS（自治系统）描述的是互联网中的路由管理范围**，一个 AS 内部可以包含多个不同规模的网络。

# 网络性能指标

## 1. 速率

**速率**表示单位时间内传输的数据量，单位通常是 `bit/s`。

```text
1 kbit/s = 10³ bit/s
1 Mbit/s = 10⁶ bit/s
1 Gbit/s = 10⁹ bit/s
```

这里的速率是**数据传输速率**，不是信号在介质中的传播速度。

另外需要注意啊，速率中使用的进制是 10 进制，而计算机存储容量中使用的进制是 2 进制。比如：1MB = 2²⁰ B = 1024 KB，而 1 Mbps = 10⁶ bps = 125 KB/s。

## 2. 带宽与吞吐量

在计算机网络中，**带宽**通常表示链路能够达到的最大数据传输速率；**吞吐量**表示实际单位时间内成功传输的数据量。

例如一条链路带宽为 `100 Mbps`，实际只能达到 `70 Mbps`，则吞吐量约为 `70 Mbps`。通常：

$$
吞吐量 \leq 瓶颈链路带宽
$$

## 3. 时延

网络总时延主要由以下四部分组成：

$$
总时延=发送时延+传播时延+处理时延+排队时延
$$

**发送时延**是把一个数据包全部送入链路所需的时间：

$$
发送时延=\frac{数据长度}{发送速率}
$$

注意可能会受到发送速率和信道带宽以及接口速率的影响。一般取他们中的最小值作为发送速率。

**传播时延**是信号从链路一端传播到另一端所需的时间：

$$
传播时延=\frac{链路距离}{传播速度}
$$

**处理时延**主要来自路由器检查数据、查询路由表等操作；**排队时延**是分组等待出口链路空闲产生的时间，网络越拥塞通常越大。

|  | 发送时延 | 传播时延 |
|---|---|---|
| 主要取决于 | 数据大小、发送速率 | 距离、传播速度 |
| 数据变大 | 增大 | 基本不变 |
| 距离变长 | 基本不变 | 增大 |

因此，**带宽提高主要降低发送时延，不会明显降低传播时延。**


比如我们常说的网速一般就是指**发送速率**，而不是传播速度。即使光纤的传播速度接近光速，但如果带宽不够大，发送时延仍然会很长。

最后还有排队时延，即分组在路由器等待转发的时间。排队时延与网络拥塞程度相关，网络越拥塞，排队时延越大。

## 4.时延带宽积

$$
时延带宽积=传播时延\times带宽
$$

它表示某一时刻**链路中正在传播的数据量**。可以理解为水管容量：带宽类似水管粗细，传播时延类似水管长度。


## 5.RTT

**RTT（Round-Trip Time，往返时间）**表示数据从发送方到接收方，再返回发送方所需的时间。`ping` 测量的主要就是 RTT。

## 6.利用率与丢包率

**利用率**表示链路被使用的程度。利用率越高不一定越好，当接近 `100%` 时，分组容易大量排队，使时延迅速增加。
$$
利用率 ≈ \frac{吞吐量}{带宽}
$$

利用率也不是越高越好，过高的利用率会导致网络拥塞，增加时延和丢包率。
$$
D = \frac{D_0}{1-U}
$$	​
其中：
\(D\)：实际网络时延
\(D_0\)：网络空闲时的时延
\(U\)：利用率
也就是说，当链路中数据过多时（利用率高），那么在链路中的分组就会大量排队，导致时延迅速增加。

**丢包率**表示发送的分组中有多少没有成功到达：

$$
丢包率=\frac{丢失的分组数}{发送分组总数}
$$

常见原因包括网络拥塞导致路由器缓存溢出，以及无线干扰等传输错误。

## 7.性能指标速记

| 指标 | 核心含义 |
|---|---|
| 速率 | 每秒传多少数据 |
| 带宽 | 最大传输能力 |
| 吞吐量 | 实际传输了多少 |
| 发送时延 | 数据进入链路需要多久 |
| 传播时延 | 信号走完链路需要多久 |
| 时延带宽积 | 链路中有多少数据正在传播 |
| RTT | 数据往返一次需要多久 |
| 利用率 | 链路有多忙 |
| 丢包率 | 有多少分组丢失 |


# 计算机网络体系结构

## 1.常见网络体系结构

**计算机网络体系结构**就是计算机网络各层及其协议的集合，用来规定网络通信系统如何分层、各层负责什么，以及各层之间如何协作。

常见体系结构主要有 OSI、TCP/IP 和教学中常用的五层体系结构。

| 体系结构      | 分层                            |
| --------- | ----------------------------- |
| OSI 七层    | 应用层、表示层、会话层、运输层、网络层、数据链路层、物理层 |
| TCP/IP 四层 | 应用层、运输层、网际层、网络接口层             |
| 五层体系结构    | 应用层、运输层、网络层、数据链路层、物理层         |

实际互联网使用的是 **TCP/IP 体系结构**；五层体系结构主要用于教学，因为它比 TCP/IP 划分更清楚，又比 OSI 更贴近实际网络。

## 2.为什么需要分层

网络通信非常复杂，如果所有功能都放在一起实现，系统会难以设计、维护和升级，因此把整个通信过程拆分为多个层次。

每一层只负责一类问题，并向上一层提供服务。例如应用层只关心应用之间如何交换数据，运输层负责端到端传输，网络层负责数据如何跨网络到达目标主机，数据链路层负责相邻设备之间传输，物理层负责真正传输比特。

分层最大的好处是**降低复杂度、明确职责、便于模块化设计和替换**。只要层与层之间的接口不变，某一层内部实现发生变化，通常不会影响其他层。

## 3.分层思想举例

发送一条网络消息时，可以简单理解为：

```text
应用数据
↓
运输层：加入运输层控制信息
↓
网络层：加入 IP 等信息
↓
数据链路层：加入链路层信息
↓
物理层：转换为比特并发送
```

接收方则执行相反过程：

```text
物理层 → 数据链路层 → 网络层 → 运输层 → 应用层
```

这个过程称为**封装与解封装**。

注意，分层并不是说数据真的先在某层停很久再进入下一层，而是协议栈按照层次快速处理数据。分层主要是**逻辑上的功能划分**。

## 4.专用术语

**实体（Entity）**是某一层中实现该层功能的软件或硬件，例如主机中的 TCP 模块可以看作运输层实体。

**对等实体**是通信双方处于同一层的实体。对等实体之间遵循相同的**协议（Protocol）**进行逻辑通信。

```text
主机 A                         主机 B
运输层实体 ←—— TCP 协议 ——→ 运输层实体
     ↓                            ↑
   服务                          服务
     ↓                            ↑
网络层实体 ←—— IP 协议 ——→ 网络层实体
```

**协议**规定同一层对等实体之间如何通信；**服务**则是下层向上层提供的功能。

可以简单记为：

> **协议是“同层之间的规则”，服务是“下层给上层的能力”。**

每层处理的数据通常称为 **PDU（Protocol Data Unit，协议数据单元）**。在不同层中常见名称也不同：

| 层次    | 常见数据单位              |
| ----- | ------------------- |
| 应用层   | 报文                  |
| 运输层   | TCP 报文段 / UDP 用户数据报 |
| 网络层   | IP 数据报 / 分组         |
| 数据链路层 | 帧                   |
| 物理层   | 比特                  |
