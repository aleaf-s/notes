# 9.4 光学成像的几何理论

光学成像的几何理论可以在不涉及任何诸如透镜或反射镜等具体光学元件的情况下进行公式化推导。这一理论是纯抽象的，但其妙处在于，在靠近光轴的区域内，实际的光学成像系统能够被该理论很好地描述。该理论可以通过严密但冗长的数学方法进行证明。在这里，我们仅对该理论的主要结果进行总结。对此有兴趣深入了解的治疗细节的读者，可以参考文献 [124，第四章] 中的讨论。

首先，让我们考虑在光学成像系统中我们希望实现什么目标。一个“理想的”成像系统应该能够为物体形成一个清晰的像。在理想情况下，这个清晰的像还应该保持物体精确的几何形状。如果物体是三维的，那么若其三维像是原始物体的精确复制品（尺寸缩放和镜像除外）则是最理想的。因此，**锐利度（sharpness）**和**相似性（similarity）**是理想光学成像系统所期望具备的两个几何特征。我们如何用数学方法来定义这两个特征呢？

如果从物空间某一点辐射出的所有光线经折射后都能汇聚到像空间的一点，我们便确实为该物点创建了一个真正锐利的点像。如果一个成像系统能够对物空间的所有点都做到这一点，我们就可以说该系统能够产生清晰的图像。然而，在实际中收集任何方向上的所有光线是不现实的，而且为了成像也无需这样做。因此，我们得出以下定义：

> **无像差（锐利）像 / 齐点像 (Stigmatic image)**
> 
> 如果从物空间物点 $P_o$ 发出的无穷多条光线通过像空间中的某一点 $P_i$，则称 $P_i$ 为 $P_o$ 的**无像差（齐点）像**。这无穷多条光线包含在由成像系统光瞳所拦截的光锥之中。物空间不需要是整个三维空间。它可以被定义为三维空间中的有限体积或区域。该物空间所有像点的集合即为像空间。这两个空间中的对应点被称为**共轭点 (conjugate points)**。

至于物体和像之间的相似性，我们可以允许镜像也被接受为相似。如果像空间中的每条曲线都与其物空间中的共轭曲线相似，我们就说该像是**完美像 (perfect image)**，且该成像过程为**完美成像 (perfect imaging)**。需要注意的是，物空间和像空间都在三维域中。

能够产生无像差（锐利）且完美（相似）图像的光学成像仪器被称为**绝对仪器 (absolute instrument)**。以下定理陈述了绝对成像仪器的重要性质：

> **关于绝对仪器的麦克斯韦定理 [125, pp. 153–156]**
> 
> 物空间中任意曲线的光程（光学长度）等于其像的光程。

> **卡拉西奥多里定理 [125, pp. 156–157]**
> 
> 绝对成像仪器在物空间和像空间之间的映射是射影变换、反演变换或这两者的组合。

上述两个定理结合起来，对绝对成像仪器所能产生的图像类型提出了非常严格的限制。如果我们希望有一个既是无像差的（锐利），又是完美的（三维像与三维物体在几何上相似）成像系统，并且物空间和像空间处于同一均匀介质空间中（即折射率相同），由于物空间中任意曲线的光程与其像的光程相同，我们只能得到一个重现与物体大小完全相同图像的成像系统。这样的系统就像一面平面镜，并不是一个非常有趣的系统。为了在相同的均匀空间中改变图像的大小，我们必须放弃无像差要求，或者放弃精确相似性的要求。

进一步可以证明 [124, p. 149]，除了诸如平面镜之类的退化情况外，旋转对称系统最多只能对两个表面进行清晰成像。在大多数由透镜和反射镜构成的实际光学成像系统中，永远无法实现三维相似性。只有在单平面或弯曲表面（即图像平面或与物体共轭的表面）的极小区域上，图像才是清晰且与物体相似的。

上述数学论证表明，即使我们无法精确实现，我们也可以将成像过程近似为**射影变换 (projective transformation)**。在近轴高斯光学中，这确实是成立的，因为此时偏轴距离和角度都被假定为很小。正如稍后所描述的，在高斯光学的假设下，对透镜、反射镜及其组合的基本性质进行的分析表明，使用旋转折射面或反射面成像是一种射影变换。还可以证明，两个绕同一轴旋转对称的相继射影变换的组合仍然是射影变换。因此我们可以得出结论：在近轴高斯光学的近似范围内，共轴系统的成像是一个射影变换。我们现在将展示，旋转对称条件下的射影变换仅用四个变量便可表征。

一个通用的射影变换可以通过物空间中的点 $(x, y, z)$ 与像空间中的点 $(x', y', z')$ 之间的以下关系来描述（见图 9.3）。两者均参考相同的笛卡尔坐标轴：


$$x' = \frac{m_{11}x + m_{12}y + m_{13}z + m_{14}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

$$y' = \frac{m_{21}x + m_{22}y + m_{23}z + m_{24}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

$$z' = \frac{m_{31}x + m_{32}y + m_{33}z + m_{34}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

让我们将 $z$ 轴设为对称轴（即光轴）。由于旋转对称性，我们只需考虑 $x = 0$ 平面上的点。射影变换简化为：

$$y' = \frac{m_{22}y + m_{23}z + m_{24}}{m_{42}y + m_{43}z + m_{44}}$$

$$z' = \frac{m_{32}y + m_{33}z + m_{34}}{m_{42}y + m_{43}z + m_{44}}$$

此外，由对称性可知，如果我们将 $y$ 变为 $-y$，$z'$ 应当保持不变，而 $y'$ 应当变为 $-y'$。因此，$m_{42}, m_{32}, m_{23}$ 和 $m_{24}$ 必须全部等于零，变换进一步简化为：

$$y' = \frac{m_{22}y}{m_{43}z + m_{44}}$$

$$z' = \frac{m_{33}z + m_{34}}{m_{43}z + m_{44}}$$

令：
$z_0 = -\frac{m_{44}}{m_{43}}$,$\quad z'_0 = \frac{m_{33}}{m_{43}}$,$\quad f = \frac{m_{22}}{m_{43}}$,$\quad f' = \left(\frac{m_{33}}{m_{22}}\right)\left(\frac{m_{34}}{m_{33}} - \frac{m_{44}}{m_{43}}\right)$

我们便得到：

$$y' = \frac{fy}{z - z_0}$$

$$z' - z'_0 = \frac{f f'}{z - z_0}$$

因此，我们仅需要四个参数 $z_0, z'_0, f$ 和 $f'$ 即可确定旋转对称成像系统的射影变换。

等式 (9.16) 被称为**牛顿公式 (Newton's equation)**。等式 (9.15) 是众所周知的**针孔相机的透视变换公式**。应当注意的是，这里推导出的公式适用于任意对称系统。它们适用于高斯（近轴）光学领域内的任何旋转对称系统。

根据等式 (9.16) 可知，如果物体位于 $z = z_0$ 处，其绝对像距 $z'$ 将为无穷大。该点被称为**物方焦点 F (object focal point F)**（也称为第一焦点或前焦点）。

同样，如果像位于 $z' = z'_0$ 处，其共轭物距 $z$ 的绝对值也为无穷大。该点被称为**像方焦点 F' (image focal point F')**（也称为后焦点）。横向放大率（垂轴放大率）$m_y$ 计算如下：

$$m_y = \frac{dy'}{dy}\Big|_z = \frac{f}{z - z_0} = \frac{z' - z'_0}{f'}$$

如果物体位于 $z = z_0 + f$ 处，则横向放大率 $m_y$ 等于 1。平面 $z = z_0 + f$ 被称为**物方主平面 (object principal plane)**（也称为第一主平面或前主平面）。同样，平面 $z' = z'_0 + f'$ 被称为**像方主平面 (image principal plane)**。物方和像方主平面与光轴分别相交于**物方主点 H** 和**像方主点 H'**（见图 9.4）。

从物方焦点 $F$ 到物方主点 $H$ 的距离为 $f$，被称为**物方焦距**。同理，$f'$ 被称为**像方焦距**。我们现在可以用以下陈述来总结：

> **旋转对称系统的射影特性**
> 
> 通用旋转对称系统的射影变换可以通过四个参数来表征：它的两个焦点和两个焦距。

现在，我们可以提出这样一个问题：旋转对称系统是一个完美的成像系统吗？答案显然是“否”，这可以通过其**轴向放大率 $m_z$** 的计算看出来：

$$m_z = \frac{dz'}{dz} = -\frac{f f'}{(z - z_0)^2} = -\frac{f'}{f}\frac{f^2}{(z - z_0)^2} = -\frac{f'}{f} m_y^2$$

轴向放大率在通常情况下并不等于横向放大率，这意味着三维像是无法与三维物体保持几何相似的。

另一个重要的放大率因子是**角放大率 (angular magnification)**。假设一个轴上物点 $A$ 位于 $z$ 处，自该物点发出的一条光线与物方主平面（位于 $z_0 + f$ 处）相交于点 $B$，点 $B$ 距离光轴为 $h$。

根据主平面的定义，$B$ 的像 $B'$ 位于像方主平面（在 $z'_0 + f'$ 处），且距离轴的距离为 $h' = h$。该光线在物方主平面处的入射角 $\theta$ 由下式给出：

$$\tan\theta = \frac{h}{z_0 + f - z}$$

出射光线在像方主平面处的出射角 $\theta'$ 由下式给出：

$$\tan\theta' = \frac{h'}{z'_0 + f' - z'}$$

因为 $h = h'$，角放大率 $m_a$ 计算为：

$$m_a = \frac{\tan\theta'}{\tan\theta} = \frac{z_0 + f - z}{z'_0 + f' - z'}$$

根据等式 (9.16)，如果 $z = z_0 - f'$，那么 $z' = z'_0 - f$，且 $m_a = 1$。这意味着，如果一条光线通过物空间中位于 $z = z_0 - f'$ 的点 $N$，它在像空间中将从位于 $z' = z'_0 - f$ 的点 $N'$ 射出，且其出射角恰好等于入射角。

这两个点 $N$ 和 $N'$ 分别被称为**物方节点 (object nodal point)** 和 **像方节点 (image nodal point)**。

![](/notes/assets/2026-06-02-9.Optical%20image%20formation/2026-06-02-11-39-13.png)

这两个焦点、两个主点和两个节点被称为光学成像系统的**基点 (cardinal points)**（见图 9.4）。它们的位置关系如下：

$$z_F = z_0$$

$$z'_{F'} = z'_0$$

$$z_H = z_0 + f$$

$$z'_{H'} = z'_0 + f'$$

$$z_N = z_0 - f'$$

$$z'_{N'} = z'_0 - f$$

另一个有用的关系将像平面与像方主点之间的距离 $s'$ 表示为 $f'$ 和 $m_y$ 的函数。由等式 (9.17) 和 (9.23)，我们得到：

$$s' = z' - z'_{H'} = (m_y - 1)f'$$

### **例题 9.1**

一个成像系统的物方焦点 $F$ 和像方焦点 $F'$ 分别位于 $z_F = 40$ 和 $z_{F'} = 120$。已知物方节点 $N$ 和像方节点 $N'$ 分别位于 $z_N = 80$ 和 $z_{N'} = 100$。

1. 该系统的物方焦距 $f$ 和像方焦距 $f'$ 是多少？
2. 主点 $H$ 和 $H'$ 的位置在哪里？
3. 如果物体位于 $z = -800$，那么其像的位置 $z'$ 在哪里？在此成像条件下的横向放大率 $m_y$ 是多少？

**【解答】**

根据等式 (9.20) 至 (9.25)：
* 物方焦距：$f = z_F - z_N = 40 - 80 = -40$ 
* 像方焦距：$f' = z_{F'} - z_{N'} = 120 - 100 = 20$ 
* 主点 $H$ 的位置：$z_H = z_F + f = 40 - 40 = 0$
* 主点 $H'$ 的位置：$z_{H'} = z_{F'} + f' = 120 + 20 = 140$

如果物体位于 $z = -800$，根据牛顿公式等式 (9.16)，像的位置 $z'$ 为：
$$z' = z_{F'} + \frac{f f'}{z - z_F} = 120 + \frac{(-40)(20)}{-800 - 40} = 120.952$$

横向放大率 $m_y$ 为：
$$m_y = \frac{f}{z - z_F} = \frac{-40}{-800 - 40} = 0.0476 $$

很明显，如果我们以两个焦点作为物空间和像空间的坐标原点，所有的公式都会变得十分简化。这样做的一个微小不便在于，焦点通常位于一些无形（不易接触）的表面上，因此不易直接测量它们到元件的距离。

对于薄透镜，主点非常靠近透镜顶点（光轴与透镜表面的交点）。因此，建立能以主点为基准测量距离的公式具有显而易见的便利性。

例如，牛顿公式 (9.16) 可以转换为以主点为距离量度基准的形式。设物点到物方主平面的距离（物距）为 $s = z - (z_0 + f)$，像点到像方主平面的距离（像距）为 $i = z' - (z'_0 + f')$，则有：

$$z' - z'_0 = \frac{ff'}{z - z_0}$$

$$i + f' = \frac{ff'}{s + f}$$

$$(i + f')(s + f) = f f'$$

$$i(s + f) = -sf'$$

$$\frac{1}{i} = -\frac{s+f}{s f'} = -\frac{1}{f'} - \frac{f}{s f'}$$

由此，我们便得出了著名的**高斯公式 (Gauss equation)**：

$$\frac{f}{s} + \frac{f'}{i} = -1$$
