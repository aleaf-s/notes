# 9.4 光学成像的几何理论

先了解一下基本概念定义：

![9.Optical image formation — 图 1]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-03-17-45-40.webp' | relative_url }})
![9.Optical image formation — 图 2]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-03-17-46-40.png' | relative_url }})


光学成像的几何理论可以在不涉及任何诸如透镜或反射镜等具体光学元件的情况下进行公式化推导。这一理论是纯抽象的，但其妙处在于，在靠近光轴的区域内，实际的光学成像系统能够被该理论很好地描述。该理论可以通过严密但冗长的数学方法进行证明。在这里，我们仅对该理论的主要结果进行总结。对此有兴趣深入了解的治疗细节的读者，可以参考文献 [124，第四章] 中的讨论。

首先，让我们考虑在光学成像系统中我们希望实现什么目标。一个“理想的”成像系统应该能够为物体形成一个清晰的像。在理想情况下，这个清晰的像还应该保持物体精确的几何形状。如果物体是三维的，那么若其三维像是原始物体的精确复制品（尺寸缩放和镜像除外）则是最理想的。因此，锐利度（sharpness）和相似性（similarity）是理想光学成像系统所期望具备的两个几何特征。我们如何用数学方法来定义这两个特征呢？

如果从物空间某一点辐射出的所有光线经折射后都能汇聚到像空间的一点，我们便确实为该物点创建了一个真正锐利的点像。如果一个成像系统能够对物空间的所有点都做到这一点，我们就可以说该系统能够产生清晰的图像。然而，在实际中收集任何方向上的所有光线是不现实的，而且为了成像也无需这样做。因此，我们得出以下定义：

> **无像差（锐利）像 / 齐点像 (Stigmatic image)**
> 
> 如果从物空间物点 $P_o$ 发出的无穷多条光线通过像空间中的某一点 $P_i$，则称 $P_i$ 为 $P_o$ 的**无像差（齐点）像**。这无穷多条光线包含在由成像系统光瞳所拦截的光锥之中。物空间不需要是整个三维空间。它可以被定义为三维空间中的有限体积或区域。该物空间所有像点的集合即为像空间。这两个空间中的对应点被称为**共轭点 (conjugate points)**。

至于物体和像之间的相似性，我们可以允许镜像也被接受为相似。如果像空间中的每条曲线都与其物空间中的共轭曲线相似，我们就说该像是**完美像 (perfect image)**，且该成像过程为**完美成像 (perfect imaging)**。需要注意的是，物空间和像空间都在三维域中。

能够产生无像差（锐利）且完美（相似）图像的光学成像仪器被称为**绝对仪器 (absolute instrument)**。以下定理陈述了绝对成像仪器的重要性质：

> **关于绝对仪器的麦克斯韦定理 [125, pp. 153–156]**
> 
> 物空间中任意曲线的光程（光学长度）等于其像的光程。

> **卡拉西奥多里定理 [125, pp. 156–157]**
> 
> 绝对成像仪器在物空间和像空间之间的映射是射影变换、反演变换或这两者的组合。

上述两个定理结合起来，对绝对成像仪器所能产生的图像类型提出了非常严格的限制。如果我们希望有一个既是无像差的（锐利），又是完美的（三维像与三维物体在几何上相似）成像系统，并且物空间和像空间处于同一均匀介质空间中（即折射率相同），由于物空间中任意曲线的光程与其像的光程相同，我们只能得到一个重现与物体大小完全相同图像的成像系统。这样的系统就像一面平面镜，并不是一个非常有趣的系统。为了在相同的均匀空间中改变图像的大小，我们必须放弃无像差要求，或者放弃精确相似性的要求。

进一步可以证明 [124, p. 149]，除了诸如平面镜之类的退化情况外，旋转对称系统最多只能对两个表面进行清晰成像。在大多数由透镜和反射镜构成的实际光学成像系统中，永远无法实现三维相似性。只有在单平面或弯曲表面（即图像平面或与物体共轭的表面）的极小区域上，图像才是清晰且与物体相似的。

上述数学论证表明，即使我们无法精确实现，我们也可以将成像过程近似为**射影变换 (projective transformation)**。在近轴高斯光学中，这确实是成立的，因为此时偏轴距离和角度都被假定为很小。正如稍后所描述的，在高斯光学的假设下，对透镜、反射镜及其组合的基本性质进行的分析表明，使用旋转折射面或反射面成像是一种射影变换。还可以证明，两个绕同一轴旋转对称的相继射影变换的组合仍然是射影变换。因此我们可以得出结论：在近轴高斯光学的近似范围内，共轴系统的成像是一个射影变换。我们现在将展示，旋转对称条件下的射影变换仅用四个变量便可表征。

一个通用的射影变换可以通过物空间中的点 $(x, y, z)$ 与像空间中的点 $(x', y', z')$ 之间的以下关系来描述（见图 9.3）。两者均参考相同的笛卡尔坐标轴：


$$x' = \frac{m_{11}x + m_{12}y + m_{13}z + m_{14}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

$$y' = \frac{m_{21}x + m_{22}y + m_{23}z + m_{24}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

$$z' = \frac{m_{31}x + m_{32}y + m_{33}z + m_{34}}{m_{41}x + m_{42}y + m_{43}z + m_{44}}$$

让我们将 $z$ 轴设为对称轴（即光轴）。由于旋转对称性，我们只需考虑 $x = 0$ 平面上的点。射影变换简化为：

$$y' = \frac{m_{22}y + m_{23}z + m_{24}}{m_{42}y + m_{43}z + m_{44}}$$

$$z' = \frac{m_{32}y + m_{33}z + m_{34}}{m_{42}y + m_{43}z + m_{44}}$$

此外，由对称性可知，如果我们将 $y$ 变为 $-y$，$z'$ 应当保持不变，而 $y'$ 应当变为 $-y'$。因此，$m_{42}, m_{32}, m_{23}$ 和 $m_{24}$ 必须全部等于零，变换进一步简化为：

$$y' = \frac{m_{22}y}{m_{43}z + m_{44}}$$

$$z' = \frac{m_{33}z + m_{34}}{m_{43}z + m_{44}}$$

令：

$$
\begin{aligned}
z_0 &= -\frac{m_{44}}{m_{43}} \\
z'_0 &= \frac{m_{33}}{m_{43}} \\
f &= \frac{m_{22}}{m_{43}} \\
f' &= \left(\frac{m_{33}}{m_{22}}\right)\left(\frac{m_{34}}{m_{33}} - \frac{m_{44}}{m_{43}}\right)
\end{aligned}
$$

我们便得到：

$$y' = \frac{fy}{z - z_0}$$

$$z' - z'_0 = \frac{f f'}{z - z_0}$$

因此，我们仅需要四个参数 $z\_0, z^{\prime}\_0, f$ 和 $f^{\prime}$ 即可确定旋转对称成像系统的射影变换。

等式 (9.16) 被称为**牛顿公式 (Newton's equation)**。等式 (9.15) 是众所周知的**针孔相机的透视变换公式**。应当注意的是，这里推导出的公式适用于任意对称系统。它们适用于高斯（近轴）光学领域内的任何旋转对称系统。

根据等式 (9.16) 可知，如果物体位于 $z = z\_0$ 处，其绝对像距 $z^{\prime}$ 将为无穷大。该点被称为**物方焦点 F (object focal point F)**（也称为第一焦点或前焦点）。

同样，如果像位于 $z^{\prime} = z^{\prime}\_0$ 处，其共轭物距 $z$ 的绝对值也为无穷大。该点被称为**像方焦点 F' (image focal point F')**（也称为后焦点）。横向放大率（垂轴放大率）$m\_y$ 计算如下：

$$m_y = \frac{dy'}{dy}\Bigr\rvert_z = \frac{f}{z - z_0} = \frac{z' - z'_0}{f'}$$

如果物体位于 $z = z\_0 + f$ 处，则横向放大率 $m\_y$ 等于 1。平面 $z = z\_0 + f$ 被称为**物方主平面 (object principal plane)**（也称为第一主平面或前主平面）。同样，平面 $z^{\prime} = z^{\prime}\_0 + f^{\prime}$ 被称为**像方主平面 (image principal plane)**。物方和像方主平面与光轴分别相交于**物方主点 H** 和**像方主点 H'**（见图 9.4）。

从物方焦点 $F$ 到物方主点 $H$ 的距离为 $f$，被称为**物方焦距**。同理，$f^{\prime}$ 被称为**像方焦距**。我们现在可以用以下陈述来总结：

> **旋转对称系统的射影特性**
> 
> 通用旋转对称系统的射影变换可以通过四个参数来表征：它的两个焦点和两个焦距。

现在，我们可以提出这样一个问题：旋转对称系统是一个完美的成像系统吗？答案显然是“否”，这可以通过其**轴向放大率 $m_z$** 的计算看出来：

$$m_z = \frac{dz'}{dz} = -\frac{f f'}{(z - z_0)^2} = -\frac{f'}{f}\frac{f^2}{(z - z_0)^2} = -\frac{f'}{f} m_y^2$$

轴向放大率在通常情况下并不等于横向放大率，这意味着三维像是无法与三维物体保持几何相似的。

另一个重要的放大率因子是**角放大率 (angular magnification)**。假设一个轴上物点 $A$ 位于 $z$ 处，自该物点发出的一条光线与物方主平面（位于 $z_0 + f$ 处）相交于点 $B$，点 $B$ 距离光轴为 $h$。

根据主平面的定义，$B$ 的像 $B^{\prime}$ 位于像方主平面（在 $z^{\prime}\_0 + f^{\prime}$ 处），且距离轴的距离为 $h^{\prime} = h$。该光线在物方主平面处的入射角 $\theta$ 由下式给出：

$$\tan\theta = \frac{h}{z_0 + f - z}$$

出射光线在像方主平面处的出射角 $\theta'$ 由下式给出：

$$\tan\theta' = \frac{h'}{z'_0 + f' - z'}$$

因为 $h = h^{\prime}$，角放大率 $m\_a$ 计算为：

$$m_a = \frac{\tan\theta'}{\tan\theta} = \frac{z_0 + f - z}{z'_0 + f' - z'}$$

根据等式 (9.16)，如果 $z = z\_0 - f^{\prime}$，那么 $z^{\prime} = z^{\prime}\_0 - f$，且 $m\_a = 1$。这意味着，如果一条光线通过物空间中位于 $z = z\_0 - f^{\prime}$ 的点 $N$，它在像空间中将从位于 $z^{\prime} = z^{\prime}\_0 - f$ 的点 $N^{\prime}$ 射出，且其出射角恰好等于入射角。

这两个点 $N$ 和 $N^{\prime}$ 分别被称为**物方节点 (object nodal point)** 和 **像方节点 (image nodal point)**。

![9.Optical image formation — 图 4]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-02-11-39-13.png' | relative_url }})

这两个焦点、两个主点和两个节点被称为光学成像系统的**基点 (cardinal points)**（见图 9.4）。它们的位置关系如下：

$$z_F = z_0$$

$$z'_{F'} = z'_0$$

$$z_H = z_0 + f$$

$$z'_{H'} = z'_0 + f'$$

$$z_N = z_0 - f'$$

$$z'_{N'} = z'_0 - f$$

另一个有用的关系将像平面与像方主点之间的距离 $s^{\prime}$ 表示为 $f^{\prime}$ 和 $m\_y$ 的函数。由等式 (9.17) 和 (9.23)，我们得到：

$$s' = z' - z'_{H'} = (m_y - 1)f'$$

### **例题 9.1**

一个成像系统的物方焦点 $F$ 和像方焦点 $F'$ 分别位于 $z_F = 40$ 和 $z_{F'} = 120$。已知物方节点 $N$ 和像方节点 $N'$ 分别位于 $z_N = 80$ 和 $z_{N'} = 100$。

1. 该系统的物方焦距 $f$ 和像方焦距 $f^{\prime}$ 是多少？
2. 主点 $H$ 和 $H^{\prime}$ 的位置在哪里？
3. 如果物体位于 $z = -800$，那么其像的位置 $z^{\prime}$ 在哪里？在此成像条件下的横向放大率 $m\_y$ 是多少？

**【解答】**

根据等式 (9.20) 至 (9.25)：
* 物方焦距：$f = z_F - z_N = 40 - 80 = -40$ 
* 像方焦距：$f^{\prime} = z\_{F^{\prime}} - z\_{N^{\prime}} = 120 - 100 = 20$
* 主点 $H$ 的位置：$z_H = z_F + f = 40 - 40 = 0$
* 主点 $H^{\prime}$ 的位置：$z\_{H^{\prime}} = z\_{F^{\prime}} + f^{\prime} = 120 + 20 = 140$

如果物体位于 $z = -800$，根据牛顿公式等式 (9.16)，像的位置 $z^{\prime}$ 为：
$$z' = z_{F'} + \frac{f f'}{z - z_F} = 120 + \frac{(-40)(20)}{-800 - 40} = 120.952$$

横向放大率 $m\_y$ 为：
$$m_y = \frac{f}{z - z_F} = \frac{-40}{-800 - 40} = 0.0476 $$

---

很明显，如果我们以两个焦点作为物空间和像空间的坐标原点，所有的公式都会变得十分简化。这样做的一个微小不便在于，焦点通常位于一些无形（不易接触）的表面上，因此不易直接测量它们到元件的距离。

对于薄透镜，主点非常靠近透镜顶点（光轴与透镜表面的交点）。因此，建立能以主点为基准测量距离的公式具有显而易见的便利性。

例如，牛顿公式 (9.16) 可以转换为以主点为距离量度基准的形式。设物点到物方主平面的距离（物距）为 $s = z - (z\_0 + f)$，像点到像方主平面的距离（像距）为 $i = z^{\prime} - (z^{\prime}\_0 + f^{\prime})$，则有：

$$z' - z'_0 = \frac{ff'}{z - z_0}$$

$$i + f' = \frac{ff'}{s + f}$$

$$(i + f')(s + f) = f f'$$

$$i(s + f) = -sf'$$

$$\frac{1}{i} = -\frac{s+f}{s f'} = -\frac{1}{f'} - \frac{f}{s f'}$$

由此，我们便得出了著名的**高斯公式 (Gauss equation)**：

$$\frac{f}{s} + \frac{f'}{i} = -1$$

如果两边都是空气，$f'= -f$，公式就变成了我们熟悉的**薄透镜公式**：$\frac{1}{i} - \frac{1}{s} = \frac{1}{f}$。 注意这里相比于我们熟悉的薄透镜多个负号是因为这里有坐标系的原因，透镜为原点，右为正。

# 9.5 光学成像中的规范与术语

在前文对通用光学成像系统的分析中，我们采用了一个在大多数光学教科书中通用的坐标系，该坐标系将在本书中继续使用。因此，我们应该在此对其进行更清晰的界定。

轴始终指向右侧，若系统具有旋转对称性，该轴即为对称轴。这一轴线被称为系统的**光轴 (optical axis)**。沿光传播方向（从左向右）测量的距离为正，反之（从右向左）测量的距离为负。例如，物方焦距 $f = z\_H - z\_0$ 代表从物方焦点 $F$ 到物方主点 $H$ 的位移。若 $H$ 位于 $F$ 的右侧，则 $f$ 为正。相应地，与物空间相反，像方主点 $H^{\prime}$ 通常位于像方焦点 $F^{\prime}$ 的左侧，因此像方焦距 $f^{\prime} = z^{\prime}\_{H^{\prime}} - z^{\prime}\_0$ 通常为负值。明确距离测量的基准点或基准面始终是极其重要的。

我们将使用右手坐标系，其中 $x$ 轴垂直指向纸面内部，$y$ 轴垂直指向纸面上方。对于旋转对称系统，假设令 $x = 0$，则物点可以仅由其 $y$ 坐标来确定。换句话说，$y$ 轴被定义在通过物点和光轴的平面上。该平面被称为**子午面 (meridional plane)**（也称为切线面 tangential plane）。位于该平面内的任意光线均称为**子午光线 (meridional ray)**。在旋转对称系统中，子午光线在通过整个系统的传播过程中会始终保持在子午面内。任何不位于子午面内的光线均称为**斜光线 (skew ray)**。

在任何实际的光学成像系统中，光线只能通过有限的孔径（见图 9.5）。该孔径可以由物理平面上的开孔（称为**孔径光阑 aperture stop**）形成，也可以代表光线通过系统路径中最窄的横截面。从物侧看去，该孔径被称为**入瞳 (entrance pupil)**；从像侧看去，则被称为**出瞳 (exit pupil)**。换句话说，入瞳是孔径光阑经其前方（即物侧）所有光学元件所成的像。类似地，出瞳是孔径光阑经其后方（即传感器侧）所有光学元件所成的像。因此，入瞳和出瞳的尺寸通常与孔径光阑的实际大小不同。例如，你看到他人眼睛里的瞳孔实际上比其真实的物理瞳孔要大，因为你看到的是其瞳孔经角膜折射放大后所成的像。

在分析成像系统时，掌握入瞳和出瞳的大小与位置是至关重要的。入瞳构成了底面，物点构成了能够被成像系统接收的光锥的顶点。类似地，出瞳构成了底面，像点则构成了汇聚到成像面上的光锥的顶点。通常，入瞳和出瞳的尺寸并不相同。出瞳直径 $a_{ex}$ 与入瞳直径 $a_{en}$ 的比值被称为**光瞳放大率 (pupil magnification)**（或光瞳因子）$m_p$，即：

$$m_p = \frac{a_{ex}}{a_{en}} \tag{9.28}$$

当讨论成像系统的辐射度学（Radiometry）和光度学（Photometry）时，该参数非常重要。

指向入瞳中心的子午光线被称为**主光线 (chief ray)**。主光线的重要性在于，它大致代表了通过光学系统的整个光束锥的几何中心。它必然穿过孔径光阑的中心。通过入瞳边缘的任意光线则被称为**边缘光线 (marginal ray)**。

包含主光线且与子午面垂直的平面被称为**弧矢面 (sagittal plane)**。位于弧矢面内的任意光线被称为**弧矢光线 (sagittal ray)**。

与光轴夹角 $\theta$ 极小的光线被称为近轴光线。光轴周围的这一极小区域被称为近轴区。近轴近似假定 $\sin \theta \approx \theta$ 且 $\cos \theta \approx 1$。如前所述，对旋转对称系统在近轴近似下进行的光学计算被称为**高斯光学 (Gaussian optics)**。

光轴与透镜前后表面相交的点被称为透镜的**前顶点**和**后顶点**。顶点是实实在在可以接触到的物理坐标点，因此实际中透镜的许多光学距离都是以这两个顶点为基准来指定的。

# 9.6 球面上的折射

在讨论完光学成像的几何理论后，我们现在来具体分析由透镜等实际元件构成的成像系统。虽然折射定律（Snell's Law）是光学分析的唯一基石，但由于实际光学系统的复杂性，对其进行纯手动的代数计算几乎是不现实的。因此，镜头设计人员主要依赖计算机运行光线追踪 (Ray Tracing) 来评估系统性能。例如，如果从某一物点发出的多条光线经系统折射后能完美汇聚到像面上的同一点，就说明该物点的画质设计非常成功。接着，我们再对其他物点进行光线追迹，便能系统地评估整个像空间的画质。显然，测试的**共轭物点**越多，对光学系统整体性能的评估就越全面。

光线追迹计算主要由计算机自动完成。但初始结构的设计依然极其依赖设计师的经验和直觉。任何共轴光学系统都可以看作是由一系列空间分离的折射面（玻璃表面）组成的。光线追迹的本质，就是数学模拟光线从物点出发，穿过一个又一个折射面、最终到达像平面的物理过程。该过程在数学上包含两个交替进行的步骤：**传输 (transfer)** 与 **折射 (refraction)**。

1. **传输过程**：模拟光线在两镜面之间的直线传播，直至与下一个折射面相交。这一步的核心是求解光线与介质表面的三维空间交点。
2. **折射过程**：在交点处，根据折射定律计算光线穿过介质表面后的新传播方向（单位向量）。

这两个过程在系统内部不断交替迭代，直到光线最终打在像平面（Sensor）上。本节我们将以球面为例，详细剖析这两个过程的数学建模。球面是光学冷加工中最基础、最核心的表面形式，因为通过两块工件的相互研磨，天然就最容易获得高精度的球面。

由于球面镜应用极其广泛，其像差（Aberrations）理论在几何光学中已经发展得十分成熟。

![9.Optical image formation — 图 7]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-03-11-01-54.png' | relative_url }})

如图 9.6 所示，设一个球面的数学方程为：
$$\phi(x, y, z) = x^2 + y^2 + (z - r)^2 - r^2 = 0$$
它与光轴（$z$轴）交于原点 $O(0,0,0)$（在此假定球半径 $r > 0$）。

一条自点 $A$ 发出的光线，沿单位方向向量 $\mathbf{I}$ 传播，并与球面交于点 $B$。球面在点 $B$ 处的单位法向量为 $\mathbf{N}$（指向球心）。入射光线经折射后的新方向向量为单位向量 $\mathbf{I'}$。

因此，**传输过程**的目标是求出交点 $B$ 的坐标；而**折射过程**的目标是求出折射方向单位向量 $\mathbf{I'}$。为了简化数学表达，我们设 $\mathbf{A}$ 和 $\mathbf{B}$ 分别为从原点 $O$ 指向点 $A$ 和点 $B$ 的位置向量。

首先求解**传输过程**。由于交点 $B$ 位于入射光线上，其空间坐标可表示为：
$$\mathbf{B} = \mathbf{A} + k\mathbf{I}$$
*(其中 $k$ 为标量系数，代表光线在空间中传播的物理距离)*。

设沿光轴（$z$轴）的单位向量为 $\mathbf{U} = [0, 0, 1]^T$，则球心位置可表示为 $r\mathbf{U}$。对于球面上任意一点 $\mathbf{R} = [x, y, z]^T$，其必满足球面方程：
$$\phi(\mathbf{R}) = x^2 + y^2 + (z - r)^2 - r^2 = x^2 + y^2 + z^2 - 2rz = \mathbf{R} \cdot \mathbf{R} - 2r\mathbf{R} \cdot \mathbf{U} = 0 \tag{9.29}$$

因为交点 $B$ 也在球面上，将位置向量 $\mathbf{B}$ 代入上述方程：

$$\phi(\mathbf{B}) = \mathbf{B} \cdot \mathbf{B} - 2r\mathbf{B} \cdot \mathbf{U} = 0 \tag{9.30}$$

$$= (\mathbf{A} + k\mathbf{I}) \cdot (\mathbf{A} + k\mathbf{I}) - 2r(\mathbf{A} + k\mathbf{I}) \cdot \mathbf{U} = 0 \tag{9.31}$$

$$= \mathbf{A} \cdot \mathbf{A} + 2k\mathbf{A} \cdot \mathbf{I} + k^2 - 2r\mathbf{A} \cdot \mathbf{U} - 2kr\mathbf{I} \cdot \mathbf{U} \tag{9.32}$$

$$= k^2 + 2(\mathbf{A} \cdot \mathbf{I} - r\mathbf{I} \cdot \mathbf{U})k + \mathbf{A} \cdot \mathbf{A} - 2r\mathbf{A} \cdot \mathbf{U} \tag{9.33}$$

$$= 0 \tag{9.34}$$

解关于距离 $k$ 的一元二次方程，可得：
$$k = -(\mathbf{A} \cdot \mathbf{I} - r\mathbf{I} \cdot \mathbf{U}) \pm [(\mathbf{A} \cdot \mathbf{I} - r\mathbf{I} \cdot \mathbf{U})^2 - \mathbf{A} \cdot \mathbf{A} + 2r\mathbf{A} \cdot \mathbf{U}]^{1/2} \tag{9.35}$$

此处所得的两个解对应光线与球体的两个交点（穿入点和穿出点）。由于我们只关心光线首次入射

球面的交点，我们需要对根的物理意义进行判定。设发光点 $A$ 位于光轴上，即 $\mathbf{A} = -\mathbf{U}$，且光线沿轴向传播，即 $\mathbf{I} = \mathbf{U}$。此时，真实的交点 $B$ 必然位于球面的顶点 $O(0,0,0)$ 处。

由此可得：$\mathbf{B} = \mathbf{A} + k\mathbf{I} = -\mathbf{U} + k\mathbf{U} = \mathbf{0}$，由于 $B$ 在原点，此时物理距离 $k$ 应该等于 1。代入方程检验可知，我们应取等式 (9.35) 中的**负号**，即实用的物理距离公式为：

$$k = -(\mathbf{A} \cdot \mathbf{I} - r\mathbf{I} \cdot \mathbf{U}) - [(\mathbf{A} \cdot \mathbf{I} - r\mathbf{I} \cdot \mathbf{U})^2 - \mathbf{A} \cdot \mathbf{A} + 2r\mathbf{A} \cdot \mathbf{U}]^{1/2} \tag{9.36}$$

确定交点 $B$ 之后，接下来进入**折射过程**来求折射方向单位向量 $\mathbf{I'}$。首先计算球面在点 $B$ 处的单位法向量 $\mathbf{N}$（利用偏导梯度公式化简）：

$$\mathbf{N} = -\frac{\nabla\phi}{\lVert \nabla\phi \rVert} = -\frac{2\mathbf{B} - 2r\mathbf{U}}{2r} = \mathbf{U} - \frac{1}{r}\mathbf{B} \tag{9.37}$$

(归一化，然后让法向量指向球心；曲面法向量等于该点梯度值，即n = （Fx，Fy，Fz）)

根据折射定律，折射方向向量 $\mathbf{I'}$ 必然位于由入射方向 $\mathbf{I}$ 与法方向 $\mathbf{N}$ 所确定的入射面内。因此，可将 $\mathbf{I'}$ 表示为这两个基底向量的线性组合：

$$\mathbf{I'} = \alpha\mathbf{N} + \beta\mathbf{I} \tag{9.38}$$

$$\mathbf{I'} \times \mathbf{N} = \alpha\mathbf{N} \times \mathbf{N} + \beta\mathbf{I} \times \mathbf{N} \tag{9.39}$$
（这里利用了叉乘公式）

$$\sin\theta' = \beta \sin\theta \tag{9.40}$$

由此可知，等式中的系数 $\beta$ 对应折射率之比：$\beta = n/n'$（其中 $n$ 为入射介质折射率，$n'$ 为透镜介质折射率）。由于 $\mathbf{I'}$ 是单位方向向量，对其进行自点积运算：

$$1 = \mathbf{I'} \cdot \mathbf{I'} = (\alpha\mathbf{N} + \beta\mathbf{I}) \cdot (\alpha\mathbf{N} + \beta\mathbf{I}) \tag{9.41}$$

$$= \alpha^2\mathbf{N} \cdot \mathbf{N} + 2\alpha\beta\mathbf{N} \cdot \mathbf{I} + \beta^2\mathbf{I} \cdot \mathbf{I} \tag{9.42}$$

$$= \alpha^2 + 2\beta(\mathbf{N} \cdot \mathbf{I})\alpha + \beta^2 \tag{9.43}$$

求解关于待定系数 $\alpha$ 的一元二次方程，可得：

$$\alpha = -\beta(\mathbf{N} \cdot \mathbf{I}) \pm [1 - \beta^2 + \beta^2(\mathbf{N} \cdot \mathbf{I})]^{1/2} \tag{9.44}$$

为了确定根的正负号，我们令入射光线垂直于表面入射，即 $\mathbf{I} = \mathbf{N}$。此时光线不发生偏折，即折射向量 $\mathbf{I'} = \mathbf{I}$，代入可得 $\alpha + \beta = 1$。为了符合这一物理实际，根的前面必须取**正号**：

$$\alpha = -\beta(\mathbf{N} \cdot \mathbf{I}) + [1 - \beta^2 + \beta^2(\mathbf{N} \cdot \mathbf{I})]^{1/2} \tag{9.45}$$

至此，折射方向向量 $\mathbf{I'} = \alpha\mathbf{N} + \beta\mathbf{I}$ 即可被唯一确定。

看到这里，你一定深有体会：虽然底层的物理公式（折射定律）极度简单，但即使面对球面这样一个最基础的几何表面，其三维空间光线追迹的数学表达也会迅速变得极其繁琐。

虽然计算机可以轻松应对这些高强度的迭代运算，但为了让人类大脑直观地建立起成像认知，我们迫切需要一种更简约、更符合物理直觉的公式。这正是我们在工程上做高斯近似（近轴近似）的根本原因——它是化繁为简的必然选择，而非我们妥协于精度。

现在，我们已经完成了单球面光线追迹的通用数学建模。下面我们将通过实际追迹几条典型光线，来具体研究以下两种经典成像情况：(1) **共轴成像（轴上点成像）** 与 (2) **离轴成像（轴外点成像）**。


### 9.6.1 共轴（轴上点）球面成像


![9.Optical image formation — 图 8]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-03-16-40-22.png' | relative_url }})

如图 9.7 所示，设轴上物点 $A$ 位于光轴上，距离球面顶点 $O$ 的距离为 $s$，即其位置向量为 $\mathbf{A} = [0, 0, s]^T$。由于物点位于顶点左侧，故坐标值 $s$ 为负数。设一条自该物点发出的光线沿方向 $\mathbf{I}$ 传播，与光轴夹角为 $\theta$，其单位方向向量表示为 $\mathbf{I} = [0, \sin\theta, \cos\theta]^T$。根据折射定律，折射光线 $\mathbf{I'}$ 必与光轴相交，设交点为 $\mathbf{C} = [0, 0, c]^T$。我们首先来研究像距 $c$ 与光线入射角 $\theta$ 的函数关系。如果该折射球面是一个完美的无像差（锐利）成像器件，那么像距 $c$ 应当仅仅取决于物距 $s$，而与入射角 $\theta$ 无关。然而，实际情况并非如此。

（注意单折射球面是指单一交界面，右边是无穷远的介质n'）

联立等式 (9.36)、(9.37) 和 (9.45)，我们可以求得像距 $c$ 关于 $\theta$ 的函数。推导过程虽繁琐但逻辑直接，最终得到一个相当复杂的非线性函数：

$$c = s + k\cos\theta + \frac{kr\alpha}{k\alpha - r\beta}\left(1 - \frac{s}{r} - \frac{k}{r}\cos\theta\right) + \frac{kr\beta}{k\alpha - r\beta}\cos\theta, \tag{9.46}$$

其中，系数 $\alpha$ 见等式 (9.45)，且：

$$\beta = \frac{n}{n'}, \tag{9.47}$$

$$k = (r - s)\cos\theta - [(r - s)^2\cos^2\theta - s^2 + 2rs]^{1/2}, \tag{9.48}$$

$$\mathbf{N} \cdot \mathbf{I} = -\frac{k}{r}\sin^2\theta + \left(1 - \frac{s}{r} - \frac{k}{r}\cos\theta\right)\cos\theta. \tag{9.49}$$

我们可以通过级数展开，对非线性的 $\sin\theta$ 和 $\cos\theta$ 进行泰勒近似：

$$\sin\theta = \theta - \frac{\theta^3}{3!} + \frac{\theta^5}{5!} - \cdots; \tag{9.50}$$

$$\cos\theta = 1 - \frac{\theta^2}{2!} + \frac{\theta^4}{4!} - \cdots. \tag{9.51}$$

对于极小角度（近轴条件），若仅采用一级线性近似，则有 $\sin\theta \approx \theta$ 且 $\cos\theta \approx 1$。此时，所有含有 $\theta$ 的二次及以上高阶项均可忽略。（在此我们再次强调，这种一级近似在线性代数中被称为线性光学。如果成像系统同时满足共轴旋转对称，该近似即为高斯光学。）

应用高斯近轴近似，我们可以将等式 (9.45) 至 (9.49) 极大化简为：$k = -s$、$\mathbf{N}\cdot\mathbf{I} = 1 + s\theta^2/r$、$\alpha = 1 - \beta$，此时像距 $c$ 可以表示为：

$$c = \frac{sr}{s + r\beta - s\beta}, \tag{9.52}$$

该式可以写成标准高斯成像公式（等式 9.27）的形式：

$$\frac{f}{s} + \frac{f'}{c} = -1, \tag{9.53}$$

其中：

$$f = \frac{\beta r}{1 - \beta} = \frac{nr}{n' - n}, \tag{9.54}$$

$$f' = \frac{r}{\beta - 1} = \frac{n'r}{n - n'}, \tag{9.55}$$

$$\frac{f}{f'} = -\frac{n}{n'}. \tag{9.56}$$

由此可见，在高斯近轴近似下，一个半径为 $r$ 的折射球面具有确定的物方焦距 $f$ 和像方焦距 $f^{\prime}$。若 $n^{\prime} > n$（例如空气中的玻璃球），则有 $f > 0$ 且 $f^{\prime} < 0$。由于物距 $s$ 和像距 $c$ 的量度起点都是球面顶点 $O$，因此物方主点和像方主点均重合于顶点 $O$ 处，即 $z\_H = 0$ 且 $z^{\prime}\_{H^{\prime}} = 0$。物方焦点位置为 $z\_0 = z\_H - f = -f$；像方焦点位置为 $z^{\prime}\_0 = z^{\prime}\_{H^{\prime}} - f^{\prime} = -f^{\prime}$。

物方节点 $N$ 的位置为 $z_N = z_H - f - f' = -(f+f') = r$，像方节点 $N'$ 的位置同样为：

$$z'_{N'} = z'_{H'} - (f+f') = r$$

可见，*两个节点均重合于球心。这在物理上非常直观：任何指向球心的光线都垂直于球面入射，因此不发生任何偏折。

此外，交点 B 的位置向量和折射方向向量 I' 在高斯近似下分别为：

$$\mathbf{B} = [0, -s\theta, 0]^T$$
$$\mathbf{I'} = \frac{\mathbf{V}}{\lVert \mathbf{V} \rVert}$$

其中：

$$\mathbf{V} = [0, [s(1-\beta)/r]\theta + \beta\theta, 1]^T$$

这些结论将在下一节构建高斯光学的矩阵方法时发挥重要作用。

![9.Optical image formation — 图 9]({{ '/assets/2026-06-02-9.Optical%20image%20formation/2026-06-03-17-18-01.png' | relative_url }})

然而，对于与光轴夹角较大的大角度非近轴光线，高斯光学近似将不再适用。图 9.8 展示了自物点 $A$ 发出的各条大角度光线

并不能完美汇聚于同一点。离光轴越远（边缘）的光线，折射后汇聚的位置越靠近球面。这种因球面物理形状导致的成像缺陷被称为**球差 (spherical aberration)**。图中点 $Q$ 是通过高斯光学计算得到的理想像点。显然，绝大多数实际光线都在更近的距离上与光轴相交。

如果我们把像面（Sensor）往球面方向移动，图像实际上会变得更清晰，但由于球差的存在，它永远无法缩成一个理想的几何点，而是呈现为一个模糊的圆斑，即**弥散圆 (circle of confusion)**。当我们将像面移动到弥散圆尺寸达到最小时，该位置即为**最佳焦面（最清晰对焦位置）**。显然，最佳焦面的具体位置取决于对弥散圆的评估定义。但通常来说，由于像差的存在，最清晰的对焦位置往往并不在理论的高斯像面上。
